## 1. StellarStream とは

StellarStream は、Stellar/Soroban 上に構築されたリアルタイム資産ストリーミングプロトコルです。従来の一括払いを継続的なストリームに変換します。

1,000ドルを1回の取引で支払う代わりに、1,000ドルを30日間にわたってストリーミングし、時間の経過とともに1日あたり約33.33ドルずつ解放できます。

```
従来方式: [----$1000----] (一括払い)
ストリーミング: [$33][$33][$33]... (継続的に解放)
```

コントラクトは正確な数式を使って解放額を計算し、受取人はいつでも獲得した分を引き出すことができます。

---

## 2. 基本概念

- **ストリーム (Stream)**: 送金者と受取人の間の継続的な支払い契約。トークンで表示されます。
- **送金者 (Sender)**: ストリームに資金を供給するアカウント。
- **受取人 (Receiver)**: 時間の経過とともに解放されたトークンを引き出すアカウント。
- **ベスティング (Vesting)**: 時間の経過とともにトークンが受取人に利用可能になるプロセス。
- **クリフ (Cliff)**: 何も解放されない任意の期間。クリフ後は通常どおりベスティングが始まります。

### ストリームのライフサイクル

1. **作成** — 送金者がトークン、総額、開始時刻、終了時刻、ベスティングカーブを指定してストリームを作成します。
2. **アクティブ (Active)** — 選択したカーブに従ってトークンが通常どおりベスティングされます。
3. **一時停止** *(任意)* — 送金者がストリームを一時停止します。ベスティングが止まり、一時停止中の時間は計算から除外されます。
4. **引き出し** — 受取人はいつでも解放済み残高を引き出せます。
5. **終了** — ストリームが終了します（完了、または送金者による早期キャンセル）。

## 3. 数学エンジン

### 3.1 線形ベスティング（デフォルト）

標準のストリーミング計算式は比例的な解放を提供します:

```
unlocked_amount = total_amount × (elapsed_time / total_duration)
```

**例**: 1,000ドルのストリームを100日間

- 25日目: 250ドル解放（25%完了）
- 50日目: 500ドル解放（50%完了）
- 100日目: 1,000ドル解放（100%完了）

### 3.2 指数カーブ（任意）

二次関数的な成長による加速ベスティング:

```
unlocked_amount = total_amount × (elapsed_time² / total_duration²)
```

**例**: 指数カーブを使った同じ1,000ドルのストリーム

- 25日目: 62.50ドル解放（6.25%完了）
- 50日目: 250ドル解放（25%完了）
- 75日目: 562.50ドル解放（56.25%完了）
- 100日目: 1,000ドル解放（100%完了）

### 3.3 クリフ対応

クリフ時刻より前は何も解放されず、その後は通常のベスティングが始まります:

```rust
if current_time < cliff_time {
    return 0;  // まだ何も解放されていない
}
// それ以外は cliff_time から end_time までで計算
```

### 3.4 精度と安全性

- **整数演算**: すべての計算で `i128` を使用（浮動小数点数なし）。
- **切り捨て除算**: 常に切り捨てて、コントラクトの支払い能力を優先。
- **オーバーフロー保護**: チェック付き乗算で算術オーバーフローを防止。
- **ダスト防止**: 最終引き出しは正確な残高を使用。

## 4. セキュリティ機能

### 4.1 再入攻撃防止

ミューテックスパターンにより、コントラクト操作中の再入呼び出しを防止します:

```rust
// ミューテックスパターンで再入呼び出しを防止
let lock_key = symbol_short!("LOCK");
env.storage().temporary().set(&lock_key, &true);
// ... 操作を実行 ...
env.storage().temporary().remove(&lock_key);
```

### 4.2 ロールベースのアクセス制御（RBAC）

きめ細かな権限を持つ3つのロール:

| ロール | 権限 |
|--------|------|
| **Admin（管理者）** | ロールの付与/剥奪、コントラクトのアップグレード、その他すべての権限 |
| **Pauser（一時停止者）** | コントラクト操作の一時停止/再開（緊急停止） |
| **TreasuryManager（財務管理者）** | プロトコル手数料の更新、財務アドレスの変更 |

### 4.3 OFAC コンプライアンス

制裁対象アドレスへのストリームを防ぐため、制限アドレスリストを維持します:

```rust
pub fn restrict_address(env: Env, admin: Address, target: Address)
pub fn unrestrict_address(env: Env, admin: Address, target: Address)
```

### 4.4 ソウルバウンドストリーム

転送できない、身元に紐づいたストリーム:

```rust
Stream {
    is_soulbound: true,  // 作成時に一度だけ設定され、不変
    receiver: verified_address,  // 変更不可
    // ... その他のフィールド
}
```

### 4.5 一時停止/再開メカニズム

送金者は `StreamState` 列挙型（`Active`、`Paused`、`Closed`）を使ってストリームを一時停止・再開できます:

```rust
// ストリームを一時停止 - ベスティングを停止
pub fn pause_stream(env: Env, stream_id: u64, caller: Address) -> Result<(), Error>

// 一時停止したストリームを再開 - 調整後の期間でベスティングを復元
pub fn resume_stream(env: Env, stream_id: u64, caller: Address) -> Result<(), Error>

// 一時停止期間は計算から差し引かれる
effective_elapsed = current_time - start_time - total_paused_duration;
```

## 5. プロトコルの使い方

### 送金者として

1. トークンを保有し、コントラクトを承認済みであることを確認します。
2. 受取人、トークン、総額、開始/終了時刻、カーブタイプを指定してストリームを作成します。
3. ストリームを監視し、必要に応じて一時停止またはキャンセルします。

### 受取人として

1. `get_user_streams` で自分のストリームを照会します。
2. `get_withdrawable_amount` で解放済み金額を確認します。
3. いつでも獲得したトークンを引き出します。

### エラーハンドリング

発生しうる一般的なエラー（完全なリストは API リファレンスを参照）:

| エラー | 意味 |
|--------|------|
| `InvalidTimeRange` | `start_time >= end_time` |
| `InvalidAmount` | 金額 <= 0 |
| `StreamNotFound` | `stream_id` が無効 |
| `Unauthorized` | 権限が不足 |
| `StreamPaused` | 一時停止中は引き出し不可 |
| `StreamIsSoulbound` | 転送は許可されていません |
| `AddressRestricted` | OFAC コンプライアンス違反 |
